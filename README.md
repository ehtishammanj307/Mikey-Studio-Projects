# Mikey Studio Projects

Monorepo of Mikey Studio web projects.

## NOVAIR | AERO ONE

A fictional electric grand tourer concept site — Vite + React 18 + TypeScript + Tailwind, with GSAP ScrollTrigger and Lenis smooth scrolling.

```bash
npm install
npm run dev        # local dev server
npm run build      # production build to dist/
npm run typecheck  # tsc --noEmit
npm run lint       # eslint
```

> NOVAIR and AERO ONE are fictional. Not a production vehicle; all specifications are illustrative.
